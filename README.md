# 🎨 Portafolio Web - Estilo Anime / Manga

¡Bienvenido/a al repositorio de mi portafolio personal! Este proyecto es una página web estática e interactiva desarrollada desde cero con una estética inspirada en el arte de anime, manga y cel-shading, utilizando tecnologías web fundamentales (HTML5, CSS3 y JavaScript).

---

## ✨ Características Principales

* **Estructura Semántica en HTML5**: Uso correcto de etiquetas como 
`<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>`.
* **Diseño Visual Temático (Anime / Manga)**:
  * Bordes negros gruesos (*cel-shading*).
  * Sombras sólidas de impacto estilo *pop-art / comic*.
  * Paleta de colores neón y patrón de fondo de puntos (*halftone dots*).
  * Tipografías estilizadas importadas de Google Fonts (`Bangers` y `Nunito`).
* **Layout Flexible**:
  * **Flexbox** en el menú de navegación, cabecera y pie de página.
  * **CSS Grid** en la sección de habilidades y galería de proyectos.
* **Diseño Responsive & Menú Hamburguesa**:
  * Adaptable a teléfonos móviles, tablets y monitores de escritorio mediante `@media queries`.
  * Menú desplegable interactivo para dispositivos móviles impulsado por JavaScript.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5**: Estructuración semántica y formularios de contacto.
* **CSS3**: Variables CSS (`:root`), Flexbox, CSS Grid, animaciones y diseño adaptativo.
* **JavaScript (ES6+)**: Manejo de eventos del DOM para la interacción del menú hamburguesa.
